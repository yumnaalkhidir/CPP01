# CPP01

42 School C++ Module 01 — memory allocation, pointers vs references, and file manipulation.

## Concepts covered
- Dynamic (new/delete) vs stack memory allocation
- Pointers to members vs references
- Switch statements (Harl exercise) and file read/replace (sed-like) utility

## Exercises
ex00 ex01 ex02 ex03 ex04 ex05 ex06 

## Build & run
Each exercise has its own Makefile:
```sh
cd exXX
make
./<binary_name>
```
